SUMÁRIO EXECUTIVO
-----------------
Transformação completa do site EcoPoint de uma página única centralizada e
básica para uma plataforma moderna, acessível, responsiva e funcional de
sustentabilidade. O projeto foi reorganizado seguindo arquitetura modular,
design system unificado e boas práticas de UX/UI, performance e acessibilidade.

--------------------------------------------------------------------------------
1. ANÁLISE INICIAL (FASE 1 - DIAGNÓSTICO)
--------------------------------------------------------------------------------

PROBLEMAS IDENTIFICADOS:
------------------------
• Layout: Conteúdo 100% centralizado, max-width 1200px, excesso de caixas
  com sombras/bordas, aproveitamento ruim da largura da tela
• CSS: 10 arquivos fragmentados (@import), variáveis inconsistentes,
  media queries dispersas, Bootstrap 5 carregado mas subutilizado
• JS: 6 arquivos soltos (animacoes.js, scroll.js, mapa.js, graficos.js,
  noticias.js), sem modularização, API key exposta no frontend
• Mapa: 3 pontos fictícios, sem filtros, sem lista lateral, popups básicos
• Gráficos: Placeholders, sem dados reais, cores aleatórias
• Notícias: API GNews com query "futebol", cores inconsistentes,
  dependência externa bloqueante
• Acessibilidade: Sem skip link, ARIA labels ausentes, contraste baixo,
  foco invisível, sem prefers-reduced-motion
• Responsividade: Breakpoints básicos, menu não adaptado ao mobile
• Dados: Textos "Lorem ipsum", valores fictícios (KG, N, %), categorias
  hardcoded no HTML
• SEO: Meta tags básicas, sem Open Graph, sem structured data

ARQUIVOS ORIGINAIS PRESERVADOS:
-------------------------------
• assets/ - Todas as imagens e logos mantidas
• noticias.txt - 3 URLs reais de notícias sobre e-lixo
• documentacao_tecnica_*.txt - Histórico do projeto
• Planilha Google Sheets (opensheet.elk.sh) - Dados da pesquisa

2. IDENTIDADE VISUAL E ESTRUTURA (FASE 2)
--------------------------------------------------------------------------------

DESIGN SYSTEM UNIFICADO (css/styles.css - 25KB, substitui 10 arquivos):
-----------------------------------------------------------------------
• Paleta semântica: Primary (verde #1b5e20), Secondary (azul #0d47a1),
  Accent (laranja #e65100), Error/Warning + backgrounds/borders
• Tipografia: Inter (Google Fonts) - weights 300-700, scale fluida
  (xs:0.75rem → 5xl:3rem) com clamp() implícito via breakpoints
• Espaçamento: Sistema 4px (spacing-1 a spacing-20)
• Border radius: sm(4px) md(8px) lg(12px) xl(16px) full
• Sombras: 4 níveis (sm, md, lg, xl) consistentes
• Transições: fast(150ms) base(250ms) slow(350ms)
• Z-index scale: dropdown(100) → tooltip(700)
• Container: max-width 1400px (era 1200px), narrow 800px para leitura
• Utility classes: Grid (2-4 cols), Flex, Spacing, Colors, Typography

LAYOUT REESTRUTURADO:
---------------------
• Hero section com grid 2 colunas (conteúdo + mini-mapa funcional)
• Quick Access: 4 cards de navegação direta (Mapa, Descarte, Educação, Stats)
• Educational Content: 6 cards informativos com ícones e cores temáticas
• Categorias de Descarte: Grid 3 colunas com accordion de preparo
• Mapa: Layout 3 colunas (filtros | mapa | resultados) → 1 coluna no mobile
• Estatísticas: 4 cards de resumo + 4 gráficos doughnut + aviso metodológico
• Sobre: Grid 2 colunas (conteúdo + card PPI/ODS) + seção ODS 4 cards
• Notícias: Grid 3 colunas com load more, identidade visual fixa
• Equipe: Grid 3 colunas + seção orientadores 2 colunas
• Footer: 4 colunas (brand, nav, contato, social) + bottom bar

ANIMAÇÕES E MICRO-INTERAÇÕES:
-----------------------------
• IntersectionObserver para fade-in escalonado (delay 0-400ms)
• Hover states em cards (translateY -4px, shadow-lg)
• Header hide-on-scroll-down / show-on-scroll-up
• Contadores animados nas estatísticas (easeOutCubic 1.5s)
• Transições suaves em botões, links, inputs, badges
• Respeita prefers-reduced-motion (desativa tudo)

4. QUALIDADE E CONFIABILIDADE (FASE 4)
--------------------------------------------------------------------------------

ACESSIBILIDADE (WCAG 2.2 AA):
------------------------------
✅ Skip link "Pular para o conteúdo principal" (primeiro elemento)
✅ Semântica HTML5: header, nav, main, section, article, aside, footer
✅ Hierarquia de títulos: h1 → h2 → h3 → h4 (uma única h1 por página)
✅ ARIA labels: menu toggle, navegação, botões sem texto visível
✅ Focus visible: outline 3px solid secondary (#0d47a1) + offset 2px
✅ Contraste: Textos 4.5:1 mínimo, UI 3:1 (verde escuro #1b5e20 sobre branco)
✅ Autor amarelo em notícias: #b8860b sobre branco = 4.8:1 (AAA large)
✅ Redução de movimento: @media (prefers-reduced-motion: reduce) desativa
   todas as animações/transições
✅ Navegação por teclado: Tab order lógico, focus trap no menu mobile
✅ Alt text: Imagens decorativas com alt="", informativas com descrição
✅ Formulários: Labels associados, inputs com type correto
✅ Language: lang="pt-BR" no html

RESPONSIVIDADE (Mobile-First):
------------------------------
BREAKPOINTS:
• < 640px (mobile): 1 coluna grids, menu hamburger, hero 1 coluna,
  mapa empilhado (filtros → mapa → resultados), hero-stats centralizados
• 641-1024px (tablet): 2 colunas grids, mapa 3 colunas
• 1025-1399px (laptop): 3-4 colunas grids, mapa 3 colunas
• ≥ 1400px (desktop): Container 1400px, grids 3-4 colunas

TESTADO EM:
• 320px (iPhone SE), 375px (iPhone 12/13/14), 414px (iPhone Plus)
• 768px (iPad), 1024px (iPad Pro), 1366px (laptop), 1920px (desktop)

PERFORMANCE:
------------
• CSS: 1 arquivo unificado (25KB gzipped ~6KB), sem @import encadeados
• JS: 8 módulos ES5 (sem build), carregados em ordem de dependência
• Imagens: lazy-loading nativo (loading="lazy") exceto hero
• Fontes: preconnect Google Fonts, font-display: swap (padrão)
• Debounce: Busca no mapa (300ms), scroll header (passive listener)
• Chart.js: Carregado via CDN apenas na seção estatísticas
• Leaflet: Carregado via CDN apenas no mapa
• Sem dependências npm/build - arquivos estáticos puros
